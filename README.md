# BlockDock

BlockDock 是一个开源的第三方启动器和游戏环境管理器，适用于 Minecraft: Java 版和 Minecraft: 基岩版。

## 功能

- 微软账号认证
- Java 版实例管理
- 支持 Fabric / Forge / NeoForge
- 模组、资源包、着色器和模组包管理
- 基岩版世界和附加组件管理
- 资源包和行为包管理
- 世界备份和恢复
- 可扩展的提供器和插件系统

## Minecraft 游戏文件

BlockDock 不会重新分发 Minecraft 游戏文件。
Minecraft 游戏下载来源默认未包含，可能通过用户配置的提供器提供。
